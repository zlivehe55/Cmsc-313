The big idea

What is Section 1.5 trying to teach?

A solution set isn't just "the answer" — it has a shape. Section 1.5 shows you how to write that shape exactly, using parametric vector form, and how homogeneous and nonhomogeneous systems relate geometrically.

The central discovery: the solutions of Ax = b are the solutions of Ax = 0 translated by one particular solution p. The homogeneous set is a line/plane through the origin; the nonhomogeneous set is that same line/plane shifted so it passes through p instead.

Every free variable becomes a parameter that traces out one direction of that line or plane. This is where the algebra of 1.2 turns into geometry you can picture.

The starting point

Homogeneous systems

A system is homogeneous if it has the form Ax = 0 — the right-hand side is the zero vector.

Ax = 0 always has at least one solution: x = 0, the trivial solution

Because x = 0 always works, the real question is never "is it consistent?" (it always is) but "does it have other solutions?"

Key fact

Ax = 0 has a nontrivial solution if and only if the equation has at least one free variable.

Section recap

A homogeneous system is Ax = 0 — and the only question worth asking is whether it has solutions besides zero.

  • Ax = 0 is always consistent because x = 0 (the trivial solution) always works.
  • Nontrivial solutions exist ⟺ there's at least one free variable — that's the test.
  • In the worked example, RREF left x₃ free, so the solution set collapsed to Span{(4/3, 0, 1)} — a line through the origin in ℝ³.
Free variable in RREF = infinitely many solutions; no free variable = only x = 0.
Vocabulary

Trivial vs. nontrivial

Trivial solution

x = 0 (every entry zero). Always a solution of Ax = 0.

Nontrivial solution

Any solution x ≠ 0 — i.e. at least one entry is nonzero. Exists ⟺ there's a free variable.

Watch the wording

"Nontrivial" means the whole vector isn't zero — it does not mean every entry is nonzero. A vector like (0, 3, 0) is perfectly nontrivial. (This is exactly the trap in IQ 1.5 question 1.)

Section recap

"Nontrivial" is a statement about the whole vector, not its individual entries.

  • Trivial = the zero vector x = 0. Nontrivial = any x ≠ 0 — even one nonzero entry is enough.
  • Vectors like (0, 4, 0) or (0, 0, 7) are perfectly nontrivial — zero entries are allowed.
  • This is the exact trap in IQ 1.5 Q1: "every entry nonzero" is not what nontrivial means.
You'll lose points if you read "nontrivial" as "no zeros anywhere" — it just means the vector isn't 0.
Writing the answer

Parametric vector form

When there are free variables, you write the solution as a sum of vectors, with each free variable as a scalar weight. For a homogeneous system this looks like

x = x₃·v   (one free variable)  ·  x = s·u + t·v   (two free variables) each free variable scales one direction vector

The set of all such x is exactly Span of the direction vectors — a line (one free variable), a plane (two), and so on, always passing through the origin.

The pattern: # of free variables = # of direction vectors = dimension of the solution set. 0 free → just the origin (point). 1 → line. 2 → plane. 3+ → "higher" but exactly the same idea.

Section recap

Parametric vector form turns a row-reduced system into a sum of direction vectors, one per free variable.

  • Solve each basic variable in terms of the free ones, then group entries by free variable to factor out one vector each.
  • The solution set is Span of those direction vectors — a line (1 free var), plane (2), and so on, always through the origin.
  • The worked example produced x = x₂·(2,1,0,0) + x₄·(−3,0,1,1) — two free variables, two directions, a plane in ℝ⁴.
# of free variables = # of direction vectors = dimension of the solution set.

Adding a constant

Nonhomogeneous systems

Now the right side isn't zero: Ax = b with b ≠ 0. When such a system has many solutions, the general solution splits into two pieces:

x = p + t·v p = one particular solution · t·v = the homogeneous solutions
Theorem 6 — the structure

Suppose Ax = b is consistent with particular solution p. Then the solution set of Ax = b is the set of all vectors p + vh, where vh ranges over all solutions of the homogeneous equation Ax = 0.

In words: solve it once (get p), solve the homogeneous version (get the directions), then add. The answer set is the homogeneous line/plane, picked up and moved so it passes through p.

The exact same direction vector (4/3, 0, 1) shows up in both — that's because changing the right-hand side from 0 to b can only shift the solution set, never change its shape or direction. The homogeneous problem decides the shape; the particular solution p decides where that shape sits.

Sanity check at x₃ = 0: homogeneous gives x = (0, 0, 0). Nonhomogeneous gives x = (−1, 2, 0) = p itself. The nonhomogeneous line is the homogeneous line plus p — every point on one becomes the matching point on the other after adding p.

Section recap

Theorem 6: a consistent Ax = b has solution set x = p + vh — one particular p, plus every homogeneous solution.

  • Procedure: solve Ax = b once to get p, then solve Ax = 0 for the directions, then add.
  • The example used b = (7, −1, −4): same direction (4/3, 0, 1) as the homogeneous case, but now shifted to pass through p = (−1, 2, 0).
  • Changing the right-hand side from 0 to b can only translate the solution set — never bend it or change its dimension.
Homogeneous gives the shape; the particular solution p gives the position.
See it · the shift

p + Span: translating the solution set

The orange line is the homogeneous solution set Span{v} (through the origin). Drag the slider to "turn on" the particular solution p — watch the entire line slide off the origin to pass through p. That shifted line is the solution set of Ax = b. Same direction, different position.

The takeaway

Homogeneous set = line/plane through 0. Nonhomogeneous set = the same line/plane translated by p. If Ax = 0 has only the trivial solution (no free variables), then Ax = b — when consistent — has a single point as its solution.

Section recap

The "shift" slider is doing exactly what adding p does algebraically — it slides the whole line off the origin.

  • At shift = 0, the line passes through the origin (the homogeneous set Span{v}).
  • At shift = 1, the line passes through p = (−1, 2) with the same direction v = (2, 1) — that's the Ax = b set.
  • If there were no free variables, the "line" would shrink to a point — a consistent Ax = b would then have exactly one solution.
Adding p moves the set rigidly — direction stays, position changes.
Worked examples

Focused examples

1
Homogeneous, one free variable

Describe the solutions of Ax = 0 when row reduction gives x₁ − 2x₃ = 0, x₂ + x₃ = 0, with x₃ free.

Solve for basic variables

x₁ = 2x₃, x₂ = −x₃, x₃ free.

Parametric vector form

x = x₃·(2, −1, 1). The solution set is Span{(2,−1,1)} — a line through the origin in ℝ³.

2
Homogeneous, two free variables

A reduced system gives x₁ = 2x₂ − 3x₄ with x₂, x₄ free (x₃ basic = 0 say). Write it in parametric vector form.

Separate the free variables

Group the x₂ terms and the x₄ terms into their own vectors:

x = x₂·(2, 1, 0, 0) + x₄·(−3, 0, 0, 1).

Geometry

Two direction vectors → the solution set is a plane through the origin (a Span of two vectors).

3
Nonhomogeneous: p + tv

The general solution of some Ax = b is x₁ = −1 + (4/3)x₃, x₂ = 2, x₃ free. Write it as p + tv.

Split into constant + free part

x = (−1, 2, 0) + x₃·(4/3, 0, 1).

Identify the pieces

p = (−1, 2, 0) is a particular solution of Ax = b. v = (4/3, 0, 1) spans the solutions of Ax = 0. The solution set is the line through p in direction v.

Section recap

Three drills covering the full p + tv playbook end-to-end.

  • Example 1: homogeneous, one free var → Span{(2, −1, 1)}, a line through 0.
  • Example 2: homogeneous, two free vars → Span{(2,1,0,0), (−3,0,0,1)}, a plane through 0.
  • Example 3: nonhomogeneous → x = (−1, 2, 0) + x₃·(4/3, 0, 1) — the same direction as the homogeneous case, shifted by p.
Read off the basic vs. free variables, group by free variable, then add p if Ax = b.
Cheat sheet

Rules & facts to remember

  1. Homogeneous = Ax = 0. Always consistent (x = 0 is the trivial solution).
  2. Ax = 0 has a nontrivial solution ⟺ there's at least one free variable.
  3. "Nontrivial" means the whole vector ≠ 0 — individual entries may still be zero.
  4. Parametric vector form: one direction vector per free variable, each scaled by that variable.
  5. Homogeneous solution set = Span of the direction vectors = line / plane / … through the origin.
  6. Nonhomogeneous consistent solution set = p + (homogeneous solutions) (Theorem 6).
  7. Geometrically: the Ax = b set is the Ax = 0 set translated by p — same shape, shifted off the origin.
  8. No free variables & consistent → a single point. One free variable → a line. Two → a plane.

In one breath

Section 1.5 gives solution sets a geometric identity. Homogeneous systems Ax = 0 always include 0 and have extra solutions exactly when there are free variables; written in parametric vector form, their solution set is a Span — a line or plane through the origin. A consistent nonhomogeneous system Ax = b has the very same shape, just translated by one particular solution p: x = p + tv.

This p-plus-Span picture returns constantly — in eigenspaces, null spaces, and the geometry of transformations.
