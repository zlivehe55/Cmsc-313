The big idea

What is Section 1.7 trying to teach?

Linear independence asks: in a set of vectors, is any one of them redundant — buildable from the others? If none is, the set is independent; if at least one is, the set is dependent.

The whole concept reduces to a single homogeneous equation. The vectors v₁, …, vₚ are linearly independent exactly when x₁v₁ + ⋯ + xₚvₚ = 0 forces every weight to be zero (the trivial solution only). If some nonzero weights also work, that's a linear dependence relation, and the set is dependent.

So everything you learned about Ax = 0 in §1.5 comes straight back: independence ⟺ no free variables ⟺ a pivot in every column.

The definition

Linear independence & dependence

x₁v₁ + x₂v₂ + ⋯ + xₚvₚ = 0 independent ⟺ only solution is all weights zero
Linearly independent

The equation above has only the trivial solution (all xᵢ = 0). No vector is redundant.

Linearly dependent

There exist weights c₁, …, cₚ not all zero with c₁v₁ + ⋯ + cₚvₚ = 0. That's a dependence relation.

The mental test

"Can I write 0 as a combination of these vectors using at least one nonzero weight?" If yes → dependent. If the only way to get 0 is to use all zeros → independent.

From vectors to matrices

Linear independence of matrix columns

Stack the vectors as columns of a matrix A. Then the dependence equation is just the matrix equation:

x₁a₁ + x₂a₂ + ⋯ + xₙaₙ = 0   ⟺   Ax = 0 each dependence relation = a nontrivial solution of Ax = 0
The matrix test

The columns of A are linearly independent if and only if Ax = 0 has only the trivial solution — equivalently, A has a pivot in every column (no free variables).

Section recap

Stacking vectors as columns turns independence into a question about Ax = 0

  • Every dependence relation among a₁, …, aₙ is literally a nontrivial solution of Ax = 0.
  • Columns independent ⟺ Ax = 0 has only the trivial solution ⟺ pivot in every column.
  • A single free variable column = a dependence relation = the columns are dependent.
You'll never test independence by hand — you'll row reduce and count pivots.

The reducer makes the verdict mechanical: row reduce [A | 0] and look at the columns

  • Pivot in every column → only trivial solution → independent.
  • Any column without a pivot (gold) = a free variable = a nontrivial solution exists → dependent.
  • This is the engine behind every independence test in the section — and behind the textbook's Example 1.
No pivot in a column = a free variable = dependence. That's the whole test.

A free variable doesn't just signal dependence — it hands you the actual dependence relation

Small cases

Sets of one or two vectors

One vector {v}

Independent ⟺ v ≠ 0. A single nonzero vector is always independent; the zero vector alone is dependent.

Two vectors {v₁, v₂}

Dependent ⟺ one is a scalar multiple of the other (they lie on one line). Otherwise independent.

Section recap

The tiny sets have no-computation rules — memorize them

  • {v}: independent ⟺ v ≠ 0. The zero vector alone is dependent.
  • {v₁, v₂}: dependent ⟺ one is a scalar multiple of the other (same line through origin).
  • For three or more vectors you must row reduce — these shortcuts only work for sizes 1 and 2.
Sets of size 1 or 2 you answer by inspection; size ≥ 3 needs row reduction (or Thm 7/8/9).
The characterization

Theorem 7 — what dependence really means

Theorem 7

An indexed set S = {v₁, …, vₚ} of two or more vectors is linearly dependent if and only if at least one of the vectors is a linear combination of the others. In fact, if S is dependent and v₁ ≠ 0, then some vⱼ (j > 1) is a combination of the preceding vectors.

Careful

Theorem 7 does not say every vector in a dependent set is a combination of the others — only that at least one is. Some vector may fail to be expressible in terms of the rest.

Section recap

Theorem 7: dependence means at least one vector is a combination of the others — not necessarily all

  • For a set of ≥ 2 vectors: dependent ⟺ some vⱼ can be written as a linear combination of the others.
  • Sharper version: if v₁ ≠ 0, then some vⱼ (j > 1) is a combination of the preceding vectors.
  • Common trap: don't claim every vector is redundant — only at least one is.
Dependent = "at least one is redundant." The §1.5 question and the §1.7 question are the same row reduction.
See it · the counting shortcut

Theorem 8 — too many vectors

Theorem 8

If a set contains more vectors than there are entries in each vector, the set is automatically linearly dependent. That is, any set {v₁, …, vₚ} in ℝⁿ is dependent whenever p > n.

Why? Stacking p vectors from ℝⁿ gives an n×p matrix. The equation Ax = 0 is then n equations in p unknowns — more unknowns than equations means a free variable is forced, so a nontrivial solution exists. Try it: bump the counts and watch.

Section recap

Theorem 8: if you have more vectors than entries, the set is automatically dependent

  • Any set {v₁, …, vₚ} in ℝⁿ with p > n is linearly dependent — no row reduction needed.
  • Reason: the matrix is n × p, giving more unknowns than equations → forced free variable → nontrivial solution.
  • Theorem 8 says nothing when p ≤ n — in that case you still have to row reduce to decide.
Count first. If p > n, you're done — declare dependent and move on.
The instant red flag

Theorem 9 — a set with the zero vector

Theorem 9

If a set S = {v₁, …, vₚ} contains the zero vector, then S is linearly dependent — no computation needed.

Why instantly? If v₁ = 0, then 1·v₁ + 0·v₂ + ⋯ + 0·vₚ = 0 is a dependence relation with a nonzero weight (the 1). So any set containing 0 fails the independence test on sight.

Section recap

Theorem 9: any set containing the zero vector is dependent on sight

  • If 0 is in the set, put weight 1 on it and 0 on everything else — instant nontrivial relation summing to 0.
  • No row reduction, no counting — just scan for the zero vector.
  • Pairs with Theorem 8 as the two "look-first" shortcuts before you ever touch a matrix.
Spot a zero vector → set is dependent. End of computation.

Focused examples

1
Test three vectors in R³

Are v₁ = (1,2,3), v₂ = (4,5,6), v₃ = (2,1,0) independent?

Row reduce [v₁ v₂ v₃ | 0]

[1 4 2 ; 2 5 1 ; 3 6 0] reduces to [1 4 2 ; 0 −3 −3 ; 0 0 0].

Read the pivots

Pivots in columns 1 and 2 only; column 3 has no pivot → x₃ is free. A free variable means a nontrivial solution exists.

Answer

Linearly dependent. Each nonzero value of x₃ gives a dependence relation among the three vectors.

2
Use Theorem 8 (just count)

Are four vectors in ℝ³ independent or dependent — without any computation?

Count entries vs vectors

Each vector lives in ℝ³ (3 entries), but there are 4 vectors. So p = 4 > n = 3.

Apply Theorem 8

More vectors than entries ⇒ automatically linearly dependent. No row reduction required.

3
Spot the zero vector

Is {(2,1), (0,0), (3,5)} independent?

Look for 0

The set contains the zero vector (0,0).

Apply Theorem 9

Any set containing 0 is linearly dependent: take weight 1 on (0,0) and 0 on the rest — that's a nontrivial relation giving 0.

Section recap

Three examples, three tools — match the shortcut to what you see

  • Example 1 (three vectors in ℝ³): no shortcut — row reduce, find a free column, declare dependent.
  • Example 2 (4 vectors in ℝ³): p > n, so Theorem 8 finishes it in one line — dependent.
  • Example 3 (set with (0,0)): zero vector spotted, Theorem 9 closes it instantly — dependent.
Before row reducing, check Thm 8 (count) and Thm 9 (look for 0). Only then commit to the matrix.
Cheat sheet

Rules & facts to remember

  1. Independent ⟺ x₁v₁ + ⋯ + xₚvₚ = 0 has only the trivial solution.
  2. Dependent ⟺ some nonzero weights give 0 (a dependence relation).
  3. Columns of A independent ⟺ Ax = 0 has only the trivial solution ⟺ pivot in every column.
  4. One vector: independent ⟺ v ≠ 0.
  5. Two vectors: dependent ⟺ one is a scalar multiple of the other.
  6. Theorem 7: dependent (≥2 vectors) ⟺ at least one is a combination of the others (not necessarily all).
  7. Theorem 8: more vectors than entries (p > n) ⇒ automatically dependent.
  8. Theorem 9: any set containing the zero vector is dependent.
  9. A free variable in Ax = 0 is the signature of dependence.

In one breath

Section 1.7 defines linear independence through one homogeneous equation: vectors are independent when the only way to combine them into 0 is with all-zero weights, and dependent when some nonzero weights work. For matrix columns that's "Ax = 0 has only the trivial solution," i.e. a pivot in every column. Three shortcuts speed up the test: a set is dependent if it has more vectors than entries (Thm 8), or contains the zero vector (Thm 9), and dependence always means one vector is a combination of the others (Thm 7).

Independence is the backbone of bases, dimension, and rank coming up.

Pivot columns for independence

Suppose A is a 7×5 matrix. How many pivot columns must A have if its columns are linearly independent? Why?

  • A
    The matrix must have 5 pivot columns. Otherwise, the equation Ax = 0 would have a free variable, in which case the columns of A would be linearly dependent.
  • B
    The matrix must have 5 pivot columns. The statements "A has a pivot position in every row" and "the columns of A are linearly independent" are logically equivalent.
  • C
    The matrix must have 5 pivot columns. If A had fewer pivot columns, then the equation Ax = 0 would have only the trivial solution.
  • D
    None of the columns of A are pivot columns. Any column of A that is a pivot column is linearly dependent with the other pivot columns.
2
Find h for dependence

Find the value(s) of h for which the vectors are linearly dependent. Justify your answer.

v₁ = (3, −3, 6)    v₂ = (6, −9, 11)    v₃ = (−2, 2, h)

Step 1 — Stack as columns & row reduce

Matrix [3 6 −2 ; −3 −9 2 ; 6 11 h]. The vectors are dependent when Ax = 0 has a free variable, i.e. when the third column has no pivot.

Step 2 — Eliminate column 1

R2 → R2 + R1: [0 −3 0]. R3 → R3 − 2R1: [0 −1 h+4]. Matrix becomes [3 6 −2 ; 0 −3 0 ; 0 −1 h+4].

Step 3 — Eliminate column 2

R3 → R3 − (1/3)R2: the column-2 entry clears, leaving R3 = [0 0 h+4].

Step 4 — When is there no third pivot?

The (3,3) entry is h + 4. If h + 4 = 0, row 3 becomes all zeros → no pivot in column 3 → a free variable → dependent. If h + 4 ≠ 0, there's a pivot in every column → independent.

The vectors are linearly dependent ⟺ h = −4

(Note: column 2 already lost its "−3 vs −1" independence cleanly; the deciding entry is h + 4, so h = −4 is the single value that forces dependence.)
