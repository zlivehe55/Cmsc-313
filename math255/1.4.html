The Matrix Equation
Ax = b

Three ways to say the same thing: a matrix equation, a vector equation, and a linear system. Multiplying a matrix by a vector is just a linear combination of the columns — and that unlocks the existence theorem.

The big idea

What is Section 1.4 trying to teach?

A matrix times a vector, Ax, is defined to be a linear combination of the columns of A, using the entries of x as weights. That single definition ties together everything from 1.3.

Once you accept that definition, three things you've seen separately collapse into one: the matrix equation Ax = b, the vector equation x₁a₁ + ⋯ + xₙaₙ = b, and the linear system with augmented matrix [a₁ ⋯ aₙ | b] — all have the same solution set.

The payoff is Theorem 4: it lists four equivalent ways of saying "Ax = b is solvable for every b" — and reduces them all to one checkable condition: A has a pivot position in every row.

The definition

The product Ax

If A has columns a₁, …, aₙ and x has entries x₁, …, xₙ, then

Ax = x₁a₁ + x₂a₂ + ⋯ + xₙaₙ a linear combination of A's columns, weighted by x's entries

For this to be defined, the number of columns of A must equal the number of entries in x. The result is a vector with as many entries as each column (i.e. as many as A has rows).

What "Ax = combination of columns" actually does

Let A be a 2×3 matrix (3 colored columns) and x have 3 entries (the weights):

Ax = 2·[1, 0] + 1·[2, 3] + (−1)·[−1, 4]
    = [2, 0] + [2, 3] + [1, −4]

Each column gets weighted by the matching entry of x; then add the column-vectors entrywise. The result has the same number of entries as one column (2 here, because A has 2 rows).

Identity matrix

Multiplying by the identity does nothing: Iₙx = x for every x in ℝⁿ. Its columns are the standard basis vectors e₁, …, eₙ.

Section recap

Ax is a linear combination of A's columns, weighted by the entries of x

  • Ax = x₁a₁ + x₂a₂ + ⋯ + xₙaₙ — that's the definition, not a theorem.
  • It's only defined when #columns of A = #entries of x; the result has as many entries as A has rows.
  • Special case: Iₙx = x, because I's columns are the standard basis vectors e₁,…,eₙ.
If you can't read "Ax" as "mix A's columns with weights x," nothing else in 1.4 will click.

The unification

Three equivalent forms

These three statements have identical solution sets. Solving any one solves all three.

Matrix equation

Ax = b — compact and powerful; the form used for the rest of the course.

Vector equation

x₁a₁ + ⋯ + xₙaₙ = b — the linear-combination view from §1.3.

Linear system

The augmented matrix [a₁ ⋯ aₙ | b] — what you actually row reduce.

Theorem 3

If A is m×n with columns a₁, …, aₙ, and b is in ℝᵐ, the matrix equation Ax = b has the same solution set as the vector equation x₁a₁ + ⋯ + xₙaₙ = b, which in turn has the same solution set as the system with augmented matrix [a₁ ⋯ aₙ | b].

Section recap

Theorem 3: matrix equation, vector equation, and linear system are the same problem

  • Ax = b,  x₁a₁ + ⋯ + xₙaₙ = b, and the system with augmented matrix [a₁ ⋯ aₙ | b] all have identical solution sets.
  • Solving any one solves all three — you'll usually row-reduce the augmented matrix because that's what you can mechanically do.
  • Use the matrix form to state things, the vector form to understand things, the system form to compute things.
Three notations, one solution set — pick whichever view makes the question easier.
The shortcut

The row–vector rule for computing Ax

The linear-combination definition is conceptual. For fast computation there's an equivalent recipe: the i-th entry of Ax is the dot product of row i of A with x.

(Ax)ᵢ = aᵢ₁x₁ + aᵢ₂x₂ + ⋯ + aᵢₙxₙ row i of A, dotted with x → entry i of the result
See it · same A, same x, row-by-row
Row-rule on the same example

Reusing A = [[1, 2, −1], [0, 3, 4]] and x = [2, 1, −1]. Take each row, multiply pairwise with x, sum it up:

Row 1 of A  ·  x  →  entry 1 of Ax (1, 2, −1) · (2, 1, −1)  =  1·2 + 2·1 + (−1)·(−1)  =  5
Row 2 of A  ·  x  →  entry 2 of Ax (0, 3, 4) · (2, 1, −1)  =  0·2 + 3·1 + 4·(−1)  =  −1

Result: Ax = [5, −1] — exactly what the column view produced. ✓

The column view defines Ax (and explains why it makes sense). The row view computes Ax (it's what you actually do on paper). Both must agree because they're the same arithmetic, just reorganized.

Both views give the same answer. Use columns to understand what Ax means (a combination of columns); use rows to compute it quickly.

Section recap

The row–vector rule: entry i of Ax is row i of A dotted with x

  • Formula: (Ax)ᵢ = aᵢ₁x₁ + aᵢ₂x₂ + ⋯ + aᵢₙxₙ — one dot product per row.
  • It gives the same answer as the column-combination definition; it's the same arithmetic regrouped.
  • The example with A=[[1,2,−1],[0,3,4]], x=[2,1,−1] gave [5,−1] both ways.
Columns tell you what Ax means; rows tell you how to compute it on paper.
The centerpiece

Theorem 4 — four equivalent statements

Let A be an m×n matrix. The following are either all true or all false:

Theorem 4
  • (a) For each b in ℝᵐ, the equation Ax = b has a solution.
  • (b) Each b in ℝᵐ is a linear combination of the columns of A.
  • (c) The columns of A span ℝᵐ.
  • (d) A has a pivot position in every row.

Why Case 2 collapsed: in the original matrix, row 3 = 2·row 2, so R3 → R3 − 2·R2 wipes it out. That ZERO row in echelon form is the visible signature of failing Theorem 4. Practical rule: row reduce A alone (not [A | b]). Pivot in every row → spans ℝᵐ → Ax = b solvable for every b. Missing a pivot in any row → fails on all four counts.
Read this carefully

This is about solvability for every b, not one specific b. The checkable condition is (d): row reduce A (just A, not [A b]) and confirm there's a pivot in every row. A pivot in every row ⟺ the columns span ℝᵐ.

Common trap: a pivot in every column is about uniqueness (that's later). A pivot in every row is about existence / spanning — that's Theorem 4.

Section recap

Theorem 4: four statements that stand or fall together

  • (a) Ax = b solvable for every b  ⟺  (b) every b is a combination of A's columns  ⟺  (c) columns span ℝᵐ  ⟺  (d) A has a pivot in every row.
  • The checkable condition is (d): row reduce A alone (not [A | b]) and count pivots per row.
  • Trap: pivot in every row = existence/spanning; pivot in every column = uniqueness (a different question, coming later).
A zero row in A's echelon form is the visible signature of failing all four parts at once.

Section recap

One mechanical test: count pivots, one per row

  • Row-reduce A and highlight pivots — three pivots across three rows means the columns span ℝ³.
  • A row that reduces to all zeros is a missing pivot, and by Theorem 4(d) the columns fail to span ℝᵐ.
  • When spanning fails, you'll always be able to find some b for which Ax = b is inconsistent.
"Spans ℝᵐ?" reduces to: "after row reduction, does every row carry a pivot?"
Worked examples

Focused examples

1
Compute Ax

Let A = [[1,2,−1],[0,−3,2]] (2×3) and x = [2,1,−1]. Find Ax.

Column / linear-combination view

Ax = 2·[1,0] + 1·[2,−3] + (−1)·[−1,2] = [2,0] + [2,−3] + [1,−2] = [5,−5].

Row / dot-product check

Row 1 · x = 1·2 + 2·1 + (−1)(−1) = 5. Row 2 · x = 0·2 + (−3)·1 + 2·(−1) = −5. Same answer: Ax = [5,−5].

2
Solve Ax = b

Solve Ax = b for A = [[1,3],[2,5]], b = [5,8].

Row reduce [A | b]

[1 3 | 5 ; 2 5 | 8]. R2 − 2R1 → [1 3 | 5 ; 0 −1 | −2], so x₂ = 2, then x₁ = 5 − 6 = −1.

Answer

x = [−1, 2]. Check: −1·[1,2] + 2·[3,5] = [−1,−2]+[6,10] = [5,8] = b. ✓

3
Do the columns span R³?

Does A = [[1,0,2],[0,1,−1],[2,1,3]] have columns that span ℝ³?

Row reduce A

R3 − 2R1 → [0,1,−1] in row 3. Then R3 − R2 → [0,0,0]. Echelon form has pivots only in rows 1 and 2 — row 3 is all zeros.

Apply Theorem 4(d)

No pivot in row 3, so A does not have a pivot in every row. Therefore the columns do not span ℝ³ — there exist vectors b for which Ax = b has no solution.

Section recap

The three worked problems map onto the three tasks 1.4 asks you to do

  • Ex 1 — Compute Ax: use column-combination or row-by-row dot products; you should get [5, −5] both ways.
  • Ex 2 — Solve Ax = b: row reduce [A | b], back-substitute, and check by recombining the columns (x = [−1, 2]).
  • Ex 3 — Span check: row reduce A alone, look for a missing pivot — here row 3 zeroed out, so columns do not span ℝ³.
If you can do these three on demand, you've operationalized everything in 1.4.
Cheat sheet

Rules & facts to remember

  1. Ax is defined as a linear combination of A's columns, weighted by x's entries.
  2. Ax is defined only when #columns of A = #entries of x.
  3. Matrix equation = vector equation = linear system — same solution set (Theorem 3).
  4. Compute Ax fast with the row–vector (dot product) rule: entry i = (row i)·x.
  5. Theorem 4: (a) Ax=b solvable for all b ⟺ (b) every b is a combination of columns ⟺ (c) columns span ℝᵐ ⟺ (d) pivot in every row.
  6. Pivot in every row → existence/spanning. Pivot in every column → uniqueness (different question).
  7. Check spanning by row reducing A alone, not [A b].
  8. Ix = x; the identity leaves vectors unchanged.

In one breath

Section 1.4 defines Ax as a linear combination of A's columns, which makes the matrix equation Ax = b, the vector equation, and a linear system three views of one problem. Theorem 4 then gives four equivalent answers to "is Ax = b solvable for every b?" — the practical one being "does A have a pivot in every row?"

This is the engine for matrix algebra, linear independence, and transformations just ahead.
