The big idea

What is Section 1.1 trying to teach?

Linear algebra begins with one practical question: given several linear equations sharing the same unknowns, what values of those unknowns make every equation true at once?

Section 1.1 hands you three things. First, the vocabulary — linear equation, system, solution, solution set, consistent vs. inconsistent. Second, a compact way to record a messy system as a grid of numbers (a matrix), so you stop rewriting variables over and over. Third, a reliable, mechanical procedure — elementary row operations — that simplifies any system into one you can read the answer off directly.

The real lesson underneath it all: solving doesn't require cleverness, it requires a systematic process. You repeatedly swap a system for an equivalent one (same solutions, simpler form) until the answer is obvious. Everything later in the course — matrices, vectors, transformations — is built on this one move.

Vocabulary

Core definitions

Linear equation

An equation where each variable appears only to the first power, with no products of variables — written a₁x₁ + a₂x₂ + … + aₙxₙ = b.

System / linear system

A collection of one or more linear equations that all involve the same variables x₁,…,xₙ.

Solution

A list (s₁, s₂,…, sₙ) that makes every equation true when substituted in for the variables.

Solution set

The set of all solutions to the system.

Equivalent systems

Two systems are equivalent if they have exactly the same solution set.

Consistent / Inconsistent

Consistent = has at least one solution. Inconsistent = has no solution.

The shape of everything

The key formula

Every single equation you meet in this section fits one template. If you can write it this way, it's linear:

a₁x₁ + a₂x₂ + ⋯ + aₙxₙ = b the a's are coefficients · b is the constant · the x's are unknowns
Quick linearity check

Linear: 4x₁ − 5x₂ = 2  and  x₃ = 2(√6 − x₁) + x₂ (rearranges fine).
Not linear: anything with x₁x₂, x², or √x₁ — variables can't multiply each other or carry powers/roots.

The only three endings

A system has exactly one of three outcomes

No matter how complicated, every linear system lands in one of these buckets — there is no fourth possibility.

0
No solution
Inconsistent. The equations contradict each other.
1
Exactly one
Consistent & unique. Lines/planes meet at a single point.
∞
Infinitely many
Consistent. The equations overlap; a free variable remains.

So the two fundamental questions about any system are: (1) Does a solution exist? (consistency) and (2) If so, is it the only one? (uniqueness).

Recording the system

Matrix notation

Writing variables repeatedly is wasteful. A matrix is just a rectangular grid that stores the numbers. Take this system:

x₁ − 2x₂ + x₃ = 0
      2x₂ − 8x₃ = 8
−4x₁ + 5x₂ + 9x₃ = −9
Coefficient matrix

Just the coefficients of the variables.

1−21 02−8 −459
Augmented matrix

Coefficients plus a final column for the constants (shown in colour).

1−210 02−88 −459−9
Matrix size

An m × n matrix has m rows and n columns — rows always come first. The augmented matrix above is 3 × 4.

The engine

Elementary row operations

These are the only three moves you're allowed. Each one turns a matrix into a row-equivalent one — different numbers, identical solution set. They are also fully reversible.

  1. Replacement. Replace a row by the sum of itself and a multiple of another row. (This is how you eliminate variables.)
  2. Interchange. Swap two rows. (Used to get a useful number into the pivot position.)
  3. Scaling. Multiply every entry in a row by a nonzero constant. (Used to turn a leading coefficient into 1.)
Why this matters

If the augmented matrices of two systems are row-equivalent, the systems have the same solution set. That's the licence to keep simplifying without changing the answer.

Putting it together

Worked example — solving a system

Solve the system from above. The strategy: eliminate downward to reach a triangular form, then back-substitute upward.

1
Eliminate x₁ from row 3. Add 4× row 1 to row 3 → the x₁ term cancels, leaving −3x₂ + 13x₃ = −9.
2
Scale row 2. Multiply by ½ so x₂ has coefficient 1: x₂ − 4x₃ = 4.
3
Eliminate x₂ from row 3. Add 3× row 2 to row 3 → x₃ = 3. The system is now triangular.
4
Back-substitute. Use x₃ = 3 to clear x₃ from the rows above, then use x₂ = 16 to clear x₂ from row 1.
10029 01016 0013
reduced form → read the answer directly

Solution: (x₁, x₂, x₃) = (29, 16, 3)

Always verify

Plug (29, 16, 3) back into the original equations. If all three come out true, your answer is "reasonable" and confirmed.

Watch for this

How to spot "no solution"

While reducing, if you ever produce a row that says 0 = (a nonzero number) — for example 0 = 5/2 — stop. That equation can never be true, so the whole system is inconsistent: it has no solution.

[ 0   0   0  |  5/2 ]   ⟶   0 = 5/2   ✗ a contradiction row = inconsistent system
Cheat sheet

Rules & facts to remember

  1. An equation is linear only if variables appear to the first power with no products, powers, or roots of variables.
  2. A system has 0, 1, or ∞ solutions — never any other count.
  3. Consistent = ≥1 solution. Inconsistent = 0 solutions.
  4. Matrix size is rows × columns, in that order.
  5. The augmented matrix = coefficient matrix + a constants column.
  6. Only three legal moves: replace, interchange, scale (scale by a nonzero constant).
  7. Row operations are reversible and preserve the solution set.
  8. Row-equivalent augmented matrices ⇒ same solution set.
  9. A row reading 0 = nonzero means the system is inconsistent.
  10. Strategy: reduce to triangular form, then back-substitute, then verify.

In one breath

Section 1.1 teaches you to take a tangle of linear equations, write it compactly as an augmented matrix, and apply three reversible row operations to simplify it into a form where the solution is obvious — while always knowing whether a solution exists and whether it's unique.

It's not about a single trick; it's about installing a repeatable algorithm. Master this, and the rest of linear algebra has a foundation to stand on.
