The big idea

What is Section 1.2 trying to teach?

Section 1.1 showed that row operations work. Section 1.2 makes them into a precise, repeatable algorithm — and gives you a way to read the answer's shape straight off the simplified matrix.

Two destinations matter here: echelon form (a "staircase" of leading entries — good enough to tell if a system is consistent) and reduced echelon form (cleaned up further so each solution can be read directly). The big theoretical payoff: the reduced echelon form is unique — every matrix leads to one and only one.

By the end you can answer the two questions from 1.1 mechanically: Is the system consistent? and Is the solution unique? — just by spotting pivots and free variables.

The target shapes

Echelon form & reduced echelon form

Echelon form (REF)

1. All nonzero rows are above any all-zero rows.
2. Each leading entry is in a column to the right of the leading entry above it.
3. All entries below a leading entry are zero.

Reduced echelon form (RREF)

All of the above, plus:
4. Each leading entry is a 1.
5. Each leading 1 is the only nonzero entry in its column.

Theorem 1 — Uniqueness of the RREF

A matrix can be reduced to many different echelon forms (depending on which operations you choose), but each matrix is row equivalent to one and only one reduced echelon matrix.

Section recap

Two target shapes — and only one of them is unique

  • REF = staircase of leading entries, zeros below each lead, any all-zero rows at the bottom.
  • RREF adds two rules: every leading entry is a 1, and each leading 1 is the only nonzero entry in its column.
  • Per Theorem 1, a matrix has many possible echelon forms but exactly one RREF — no matter which row operations you choose.
REF is what you reach; RREF is where the answer lives.
Key vocabulary

Pivot positions & pivot columns

Pivot position

A location in a matrix that holds a leading 1 in the matrix's reduced echelon form.

Pivot column

A column that contains a pivot position.

Pivot

A nonzero number in a pivot position, used to create zeros in the rest of its column.

Pivots are the whole game in 1.2: where they land tells you which variables are determined, which are free, and whether the system is solvable at all.

Three closely related words — position, column, value

The procedure

The row reduction algorithm

Steps 1–4 are the forward phase (produce an echelon form). Step 5 is the backward phase (produce the unique reduced echelon form).

  1. Leftmost nonzero column. Start with the leftmost column that isn't all zeros — this is a pivot column; the pivot position is at its top.
  2. Choose a pivot. Pick a nonzero entry in that column as the pivot. Interchange rows if needed to move it into the pivot position.
  3. Create zeros below. Use replacement operations to make every entry below the pivot zero.
  4. Cover & repeat. Ignore the pivot row, and apply steps 1–3 to the submatrix that remains. Repeat until there are no more nonzero rows to process. → you now have an echelon form.
  5. Backward phase. Starting from the rightmost pivot and moving up-left, create zeros above each pivot, and scale each pivot to 1. → you now have the reduced echelon form.

Section recap

Five steps, two phases — forward then backward

  • Forward phase (steps 1–4): find the leftmost nonzero column, swap a nonzero entry into the pivot position, zero out everything below it, then cover that row and repeat → echelon form.
  • Backward phase (step 5): starting from the rightmost pivot, zero everything above each pivot and scale each pivot to 1 → reduced echelon form.
  • The algorithm is deterministic in its result (RREF is unique), even though the operations along the way aren't.
Forward gets you to REF; backward turns REF into the unique RREF.

Reading the answer

Basic variables vs. free variables

Basic variable

A variable whose column is a pivot column. It's pinned down by the equations.

Free variable

A variable whose column has no pivot. You may choose any value for it; the basic variables then follow.

To write the general solution: solve each pivot equation for its basic variable in terms of the free variables. Each choice of the free variables gives a different solution — that's why a free variable means infinitely many solutions.

Example

From a reduced system x₁ − 5x₃ = 1, x₂ + x₃ = 4, with x₃ free: write x₁ = 1 + 5x₃, x₂ = 4 − x₃, x₃ free. Pick x₃ = 0 → (1, 4, 0); pick x₃ = 1 → (6, 3, 1).

Section recap

Pivot column → basic; no pivot → free

  • Basic variables live in pivot columns and are determined by the equations; free variables live in pivot-less columns and you choose them.
  • To write the general solution, solve each pivot row for its basic variable in terms of the free ones — e.g. x₁ = 1 + 5x₃, x₂ = 4 − x₃, x₃ free.
  • Every choice of free variable produces a different valid solution — that's literally where "infinitely many" comes from.
Each free variable is one knob you can turn; turn it and the basic variables follow.
The payoff theorem

Existence and uniqueness

Theorem 2 — Existence & Uniqueness

A linear system is consistent if and only if the rightmost (constants) column is not a pivot column — equivalently, no echelon row looks like [0 … 0 | b] with b nonzero.

If consistent, then it has (i) a unique solution when there are no free variables, or (ii) infinitely many solutions when there is at least one free variable.

Consistency check

Is the last column a pivot column? If yes → no solution. If no → solvable.

Uniqueness check

Any free variables? None → exactly one solution. At least one → infinitely many.

Section recap

Theorem 2 resolves the two big questions in one sweep

  • Consistent ⇔ the rightmost (constants) column is not a pivot column — i.e. no echelon row of the form [0 … 0 | b] with b ≠ 0.
  • If consistent and no free variables, the solution is unique.
  • If consistent and ≥ 1 free variable, there are infinitely many solutions.
Two glances at the pivots — last column, then every other column — settle the whole system.
The full routine

Using row reduction to solve a system

  1. Write the augmented matrix of the system.
  2. Row reduce to an echelon form. Decide if it's consistent — if a row says 0 = nonzero, stop, no solution.
  3. If consistent, continue to reduced echelon form.
  4. Write the system of equations that matches the reduced matrix.
  5. Solve each equation for its basic variable in terms of any free variables.
Section recap

The whole routine in one line: augment → reduce → read off

  • Build the augmented matrix, drive to REF, and check for an inconsistent row [0 … 0 | b] with b ≠ 0 — if you find one, stop, no solution.
  • Otherwise finish to RREF, rewrite the rows as equations, and solve each pivot equation for its basic variable in terms of the free ones.
  • The output is the general solution — one formula that captures every solution at once.
No clever algebra needed — the algorithm is the method.
Cheat sheet

Rules & facts to remember

  1. Echelon form: staircase of leading entries, zeros below each, zero rows at the bottom.
  2. Reduced echelon form: echelon + leading 1's that are alone in their columns.
  3. A matrix has many echelon forms but one unique reduced echelon form (Theorem 1).
  4. Pivot column = column with a pivot position = a basic variable.
  5. A column with no pivot = a free variable = you choose its value.
  6. Consistent ⇔ the last column is not a pivot column (no [0…0 | b≠0] row).
  7. Consistent & no free variables ⇒ exactly one solution.
  8. Consistent & ≥1 free variable ⇒ infinitely many solutions.
  9. Forward phase (steps 1–4) → echelon; backward phase (step 5) → reduced echelon.

In one breath

Section 1.2 turns row operations into a fixed algorithm that drives any matrix to echelon form and then to its one unique reduced echelon form. Pivot positions tell you the basic variables; columns without pivots are free. From there you instantly know whether a system has no solution, exactly one, or infinitely many.

This is the computational backbone of the whole course — almost everything later runs row reduction underneath.
