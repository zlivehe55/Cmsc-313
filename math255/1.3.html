The big idea

What is Section 1.3 trying to teach?

Sections 1.1–1.2 were about rows of a matrix — equations. Section 1.3 flips to the columns, and reinterprets the whole subject in terms of vectors.

You learn that a vector is just an ordered list of numbers you can add and scale, and that combining vectors with chosen weights — a linear combination — is the central operation. The punchline that everything builds toward: the vector equation x₁a₁ + x₂a₂ + ⋯ + xₙaₙ = b has the same solution set as the linear system whose augmented matrix is [a₁ a₂ ⋯ aₙ | b].

So "can I reach b by combining the columns?" and "is this system consistent?" are one question asked two ways. That equivalence is the bridge between the row world and the column world, and it powers the rest of the course.

The objects

Vectors in R²

A vector in ℝ² is a column of two numbers, like [3, 1]. You can picture it as a point in the plane, or as an arrow from the origin to that point. Two vectors are equal only if all their entries match.

Addition

Add entrywise: [a,b] + [c,d] = [a+c, b+d]. Geometrically, the parallelogram rule.

Scalar multiple

Multiply every entry by the scalar: c·[a,b] = [ca, cb]. Stretches, shrinks, or flips the arrow.

Zero vector

0 = [0,0] — the origin. Adding it changes nothing.

Section recap

A vector in ℝ² is a column of two numbers — a point, or an arrow from the origin to that point.

  • Two vectors are equal only if every entry matches — order and position count.
  • Two operations are legal: entrywise addition [a,b]+[c,d]=[a+c,b+d] (parallelogram rule) and scalar multiplication c·[a,b]=[ca,cb] (stretch / shrink / flip).
  • The zero vector 0=[0,0] sits at the origin and is the identity for addition.
A vector is just data you can add and scale — the geometry comes for free.

Parallelogram rule

To add u + v, slide v's tail to u's tip — the sum reaches the far corner of the parallelogram the two arrows define. Order doesn't matter: u + v = v + u.

Section recap

Vector arithmetic is geometry you can draw: addition makes a parallelogram, scaling slides along one line.

  • u + v = the far corner of the parallelogram built from u and v — equivalently, slide v's tail onto u's tip.
  • c·u stays on the same line through the origin: c>1 stretches, 0<c<1 shrinks, c<0 flips the direction.
  • Addition is commutative (u+v = v+u), so order of the two arrows never changes the sum.
If you can picture the parallelogram and the stretch, you have all of vector algebra in ℝ².
Going general

Vectors in Rⁿ

Everything extends to any number of entries. ℝⁿ is the set of all columns of n real numbers. The same two operations — addition and scalar multiplication — work entrywise, and obey the familiar algebra rules.

u + v = v + u  ·  (u + v) + w = u + (v + w)  ·  c(u + v) = cu + cv the algebraic properties of Rⁿ — same as ordinary arithmetic

We can't draw ℝ⁴ or ℝ⁵, but the algebra is identical to ℝ². That's the power of the vector viewpoint: geometric intuition from the plane carries over to dimensions you can't picture.

Section recap

ℝⁿ is just longer columns — the rules from ℝ² survive in every dimension.

  • A vector in ℝⁿ is an ordered column of n real numbers; add and scale entrywise, exactly as in ℝ².
  • The same algebra laws hold: commutativity u+v=v+u, associativity (u+v)+w=u+(v+w), and distributivity c(u+v)=cu+cv.
  • You can't draw ℝ⁴⁺, but the algebra is unchanged — so 2D pictures still guide your reasoning.
Trust the algebra: whatever holds in ℝ² holds in ℝⁿ.
The central operation · builder

Linear combinations

Given vectors v₁, v₂, … and weights (scalars) c₁, c₂, …, the vector c₁v₁ + c₂v₂ + ⋯ is called a linear combination. Choose the two weights below and watch the result get built: first c₁·v₁, then add c₂·v₂ tip-to-tail.

Section recap

A linear combination is what you get by scaling each vector and adding the results.

  • Form: c₁v₁ + c₂v₂ + ⋯ where the cᵢ are scalar weights you choose.
  • Building it is tip-to-tail: walk c₁·v₁ first, then add c₂·v₂ from there — the gold arrow is the result.
  • Different weights give different results — the collection of every result is the span (next section).
Pick weights, scale each vector, stack tip-to-tail — that one move powers the rest of the chapter.
The bridge

Vector equation ↔ linear system

Here is the key identity of the whole section. The vector equation

x₁a₁ + x₂a₂ + ⋯ + xₙaₙ = b asks: which weights combine the a's to make b?

has exactly the same solution set as the linear system whose augmented matrix is [ a₁ a₂ ⋯ aₙ | b ]. The columns become the vectors; the unknown weights become the variables.

The equivalence

"Is b a linear combination of a₁, …, aₙ?"  ⟺  "Is the system [a₁ ⋯ aₙ | b] consistent?" These are the same question. To answer either, row reduce the augmented matrix.

Section recap

The vector equation and the linear system are the same problem in two outfits.

  • The vector equation x₁a₁ + ⋯ + xₙaₙ = b has the same solution set as the system with augmented matrix [a₁ a₂ ⋯ aₙ | b].
  • Each aᵢ becomes a column; each unknown xᵢ becomes a variable; the right side b becomes the augmented column.
  • So "is b a linear combination of the aᵢ?" ⟺ "is [a₁ ⋯ aₙ | b] consistent?" — answer either by row reduction.
Row reduction now answers a geometry question — that's the bridge the whole course rides on.
See it · the reachable set

Span — everything you can build

The span of a set of vectors is the collection of all their linear combinations — every point you can possibly reach. In ℝ², two vectors usually span the whole plane, but in special cases the span collapses to a line or a single point. Toggle below.

In R³

The same idea: one nonzero vector spans a line, two independent vectors span a plane through the origin, three independent vectors span all of ℝ³. Span is always a line, plane, … through the origin.

Section recap

Span = every point you can reach by linear combinations — and it always passes through 0.

  • In ℝ²: two independent vectors span the whole plane; one a scalar multiple of the other shrinks the span to a line; two zero vectors give just the origin.
  • In ℝ³: one nonzero vector → line, two independent → plane, three independent → all of ℝ³ — always a flat object through the origin.
  • Because the zero combination 0·v₁ + 0·v₂ + ⋯ = 0 is always available, 0 is in every span.
The span tells you what's reachable; if b lies outside it, no choice of weights will ever build b.

Section recap

To test "is b in Span{a₁, a₂}?", solve x₁a₁ + x₂a₂ = b and see if it has any solution.

  • When the a's are independent (span the plane), every b in ℝ² is reachable — there's a unique weight pair.
  • When the a's are dependent (one is a multiple of the other), they only span a line — b is reachable only if it sits on that line.
  • Mechanically: row-reduce [a₁ a₂ | b]. A [0 0 | nonzero] row means inconsistent → b is NOT in the span.
Membership in a span is a consistency question — let the augmented matrix decide.
Worked examples

Four focused examples

1
Compute a linear combination

Let u = [1, −2] and v = [3, 1]. Find 2u − v.

Work

2u = [2, −4] and −v = [−3, −1].

Add entrywise: 2u − v = [2−3, −4−1] = [−1, −5].

2
Is b a linear combination?

Can b = [7, 4] be written as a combination of a₁ = [1, 2] and a₂ = [3, 1]?

Set up the system

We need x₁[1,2] + x₂[3,1] = [7,4], i.e. x₁ + 3x₂ = 7 and 2x₁ + x₂ = 4.

Solve

From the augmented matrix [1 3 | 7 ; 2 1 | 4], eliminate: R2 − 2R1 → −5x₂ = −10, so x₂ = 2, then x₁ = 7 − 6 = 1.

Answer

Yes — b = 1·a₁ + 2·a₂. The system is consistent, so b is in Span {a₁, a₂}.

3
When b is NOT in the span

Is b = [1, 5] in Span {a₁, a₂} where a₁ = [2, 4] and a₂ = [1, 2]?

Notice the columns

a₂ = [1,2] and a₁ = [2,4] = 2·a₂ — the two vectors are multiples of each other, so they only span a line (all multiples of [1,2]).

Check b against that line

Is [1,5] a multiple of [1,2]? That would need 5 = 2·1 = 2 — false. So b is off the line.

Answer

No — b is not in the span. The system [2 1 | 1 ; 4 2 | 5] reduces to a 0 = 3 contradiction row: inconsistent.

4
Translate a vector equation to a system

Write the vector equation x₁[1,−1,0] + x₂[2,3,1] = [4,1,2] as a system of equations.

Match entries row by row

Row 1: x₁ + 2x₂ = 4

Row 2: −x₁ + 3x₂ = 1

Row 3: 0·x₁ + x₂ = 2

Augmented matrix

[1 2 | 4 ; −1 3 | 1 ; 0 1 | 2]. Each vector became a column; each entry-row became an equation. Solving it answers whether b is reachable.

Section recap

Four problem types you'll meet — each one is a small drill on the same vector ↔ system idea.

  • Compute a combination (Ex 1): scale each vector by its weight, add entrywise — pure arithmetic, no system.
  • Membership in a span (Ex 2 & 3): set up x₁a₁ + x₂a₂ = b, row-reduce; consistent → b is in the span, contradiction → it isn't.
  • Translate (Ex 4): a vector equation becomes a system by reading off one equation per row of the columns.
Watch for dependent columns (Ex 3): when one a is a multiple of the other, the span collapses to a line.
Cheat sheet

Rules & facts to remember

  1. A vector is an ordered list of numbers; equal only if all entries match.
  2. Add entrywise; scalar-multiply every entry. Geometrically: parallelogram rule and stretch/flip.
  3. A linear combination is c₁v₁ + c₂v₂ + ⋯ with chosen scalar weights.
  4. The vector equation x₁a₁ + ⋯ + xₙaₙ = b has the same solution set as the system [a₁ ⋯ aₙ | b].
  5. b is in Span{a₁,…,aₙ} ⟺ that system is consistent.
  6. Span = the set of all linear combinations = everything reachable. Always passes through 0.
  7. In ℝ²: independent pair → whole plane; one a multiple of the other → a line; both zero → just the origin.
  8. To test membership or find weights, row reduce the augmented matrix.

In one breath

Section 1.3 reframes linear algebra around vectors: lists of numbers you add and scale. Combining them with weights gives linear combinations, and the set of all such combinations is the span. The headline result is that a vector equation and a linear system are the same problem in different clothing — so "can I build b from these columns?" is answered by row reducing, exactly as before.

This column-view is the foundation for matrix–vector products, independence, and transformations coming up next.
